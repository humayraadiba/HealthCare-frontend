# Healthcare Web Application – Frontend

This is the frontend part of a Healthcare Web Application developed as part of the Web Engineering Lab course.

## Technology Stack
- React.js
- HTML5
- CSS3
- JavaScript

## Features Implemented
- Login page UI
- Patient dashboard
